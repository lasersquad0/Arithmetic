Утилита для тестирования WCX плагинов Total Commander`а.
Версия 0.22

Реализует алгоритм описанный в "WCX Writer's Reference" для проверки
функциональности плагина.

Программа может быть полезна, потому что плагин будет работать в текстовом
режиме и сможет писать в стандартные файлы stdout и stderr, т.е. на консоль.
Или просто для работы с архивом при помощи WCX плагина.

Командная строка:

    TestTCPlugin.exe [-f | -l | -c | -t | -x] <wcx_path> <arc_path> [<dir_path>]

<wcx_path> - имя файла WCX плагина

<arc_path> - имя файла архива

<dir_path> - каталог, куда распаковывать файлы. По умолчанию -- текущий

        -f - список экспортируемых функций плугина

        -l - список файлов в архиве (по умолчанию)

	-c - показать собственное окно настроек плагина	

        -t - тест файлов в архиве

        -x - извлечение файлов из архива

    -?, -h - справка

        -v - подробные сообщения программы

ERRORLEVEL будет установлена:

    0 - всё нормально,

    не 0 -- ошибка, см. сообщения программы.


Примечания:

    Вместо минуса (-) в ключах можно использовать слэш (/).

    Ключи и названия команд НЕ чувствительны к регистру (т.е. -l равно -L). Их
    порядок -- произволен.

    Программа не тестировалась с именами файлов, содержащими не-ASCII символы.
    Например, "c:\Гиви Хакеридзе\Склад\Мои записки.ha".
